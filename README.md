# 文字钓鱼 · 吐梨邦插件

文字类钓鱼小游戏：**抛竿 → 立刻咬钩（手感预抽）→ 收杆中鱼**，100 种鱼图鉴 + 道具商城（按稀有度提升概率）+ 金币结算 + 稀有鱼 AI 台词 + 每日经营圈（签到 / 任务 / 行情 / 天气 / 成就 / 日报）。
基于官方插件体系（create-pet-plugin）。

| 项目 | 值 |
|---|---|
| 插件 ID | `fishing` |
| 当前版本 | 0.5.1 |
| 最低宿主版本 | 0.29.3（Windows 11 实测） |
| SDK 契约 | `apiVersion: 1` |
| Node 内建模块 | **不使用**（`nodeAccess: false`） |
| 联网 | 仅 `net:api.open-meteo.com`（open-meteo 免 key 天气接口），无其它域名 |

## 装法

**市场安装（推荐）**：吐梨邦「设置 → 插件中心 → 插件市场」搜索「文字钓鱼」。
首次联网拉天气时宿主会弹一次 `api.open-meteo.com` 的域名授权。

**手动安装（开发调试用）**：下载 `plugin.zip` 解压后，在
「设置 → 插件中心 → 开发者模式 → 手动安装 → 从文件夹安装」选择解压目录。
手动安装不经过审核，只用于本地调试。

装好后：

- 插件面板「文字钓鱼」：钓鱼页（水面状态卡 + 增益徽章 + **行情/天气条** + 渔获记录）/ 图鉴页（100 种收集进度）/ 任务页（**签到行** + 每日 3 个任务）/ 商店页（道具购买）。
- 宿主看板出现「文字钓鱼」卡片：金币 / 累计渔获 / 图鉴进度 + 状态 + **行情/天气行** + 抛竿快捷按钮。
- 抛竿后宠物脚下出徽标（`鱼讯!`/`大鱼!`/`巨物!` 按手感档位）+ 桌宠冒泡差异化咬钩台词 + `unread`/`greet` 动作。
- SR/SSR 上鱼时宿主大模型生成一句专属台词（再冒泡一次、写进渔获记录；无 key/限流自动降级预写台词）。
- 宿主 Agent 可直接调用 7 个工具（见下表），对它说「帮我抛竿」「今天什么行情」「我签到没」即可。

## 核心循环

```
抛竿(fishing_cast) → 立刻咬钩：稀有度瞬间预抽定型（手感），气泡/徽标/文案按档位差异化
  （N/R：鱼讯! · SR：大鱼! · SSR：巨物! + greet 动作；45 秒收杆窗口）
  → 窗口内收杆(fishing_reel)：按预抽档位落具体鱼，金币入账、图鉴+1、SR/SSR 触发 AI 台词
  → 超时（5 秒巡检判定）：跑鱼（escapes +1）
收竿回家(fishing_giveup) = 不结算直接结束
```

> v0.3.0 修复：旧版增益在收杆重抽时实际不生效（耐久已先被消耗，重抽用的仍是基础概率）；改为抛竿时预抽后，道具概率真正落进鱼种。

## 每日经营圈（v0.5.0）

一条「开档即发生」的惰性链：`ensureDaily = 任务刷新 → 签到 → 行情 → 天气`，任何抛竿/查状态都会校对，错过零点也没事。

- **连续签到**：每天首次触达自动签，奖励 5→11 币递增（第 7 天封顶），断签从 5 重来；面板任务页显示连签天数。
- **鱼市行情**：每天随机 1 种鱼涨价（N ×3 / R ×2 / SR·SSR ×1.5，抽中分布偏向 N/R），行情词由大模型吆喝生成（失败降级模板），命中行情鱼按倍率结算，消息带「（行情 ×3）」。
- **天气鱼情**：拉 open-meteo 免 key 实况（默认北京坐标，缓存 3 小时），小雨/大雨/风雪雷暴分别给 SR/SSR 概率增益（与道具同规则叠加，**不耗耐久**）；多云微涨 R。无网/未授权静默按晴天处理，失败 30 分钟后再试。
- **图鉴里程碑**：集齐 10/30/60/100 种一次性发 50/150/400/1000 币 + 庆祝冒泡 + AI 祝贺台词（每档只领一次）。
- **23:58 日报**：scheduler.daily 结算今天——抛竿数 / 中鱼数 / 入账 / 最贵鱼，一段气泡播报；宿主当时不在线就错过，不补。

## 每日任务与跨插件经济圈（v0.4.0）

- **每日任务板**：每天随机 3 个任务（抛竿数 / 中鱼数 / R+、SR+ 中鱼 / 渔获入账 / 购买道具 / 完成待办），
  达标**自动发币**并冒泡。惰性跨天刷新——不依赖 scheduler，任何一次抛竿/查状态都会校对日期，错过零点也没事。
- **todo 联动**：监听 `todo-reminder:completed`（到点提醒 v1.0.3 起广播的契约事件），每完成一条待办：
  - 立到账 **5 币摸鱼佣金**（不占任务名额，天天都有）；
  - 若今日任务里刷出「完成 1 条待办」，额外 +25 币。
- 任务奖励合计约 20~70 币/天，加签到 5~11 币，是钓鱼币的主要兜底收入。

## 鱼种与概率（100 种，咬钩瞬间预抽定型）

| 稀有度 | 基础概率 | 数量 | 单条价值 |
|---|---|---|---|
| N 常见 | 60% | 40 | 1~8 币 |
| R 稀有 | 30% | 30 | 10~18 币 |
| SR 史诗 | 9% | 20 | 55~90 币 |
| SSR 传说 | 1% | 10 | 500~1000 币 |

基础期望约 **19.7 币/竿**（SSR 一档占 7.3，节奏偏「攒着等爆」）。雨天钓 SR/SSR 期望上浮约 15~25%。

## 道具商城（买完立刻生效，随抛竿消耗耐久）

| 道具 | 价格 | 效果 | 生效 | 预期回收率 |
|---|---|---|---|---|
| 🪱 幸运饵 | 6 币 | R +15% | 5 竿 | ≈1.28 |
| 🧪 浓香诱食剂 | 20 币 | SR +12% | 3 竿 | ≈1.24 |
| ✨ 黄金鱼饵 | 120 币 | SR +15% / SSR +7% | 2 竿 | ≈1.02 |
| 🌟 龙王秘药 | 180 币 | SSR +25%（SSR 概率 26%） | 1 竿 | ≈1.01 |

回收率 = 道具全周期预期收益 / 售价（按 100 鱼价值均值估算）。定价原则：低档微赚鼓励买，高档基本回本靠脸。

> v0.5.1 叠加规则：同类/跨类道具可叠加，但单档抽中率有硬顶（R 60% / SR 50% / SSR 50%）；
> 叠加总和超出基础分布的部分按 N → R → SR 顺序回收，保证抽签分布总和恒为 1，
> 任何购买组合下 SSR 机会都不会低于基础 1%（修复 v0.5.0 多饵叠加把 SSR 区间挤没的问题）。

概率数学：`effectiveWeights(buffs)` 把所有增益加到对应档位，单档封顶（R 60% / SR 50% / SSR 50%），
再把总和超出 1 的部分按 N → R → SR 顺序回收（SSR 永不回收），保证分布总和恒为 1。
多个增益可叠加；天气增益在抛竿时临时拼进权重（不耗耐久），道具增益照常消耗。

## tool 注册的 7 个工具

| 工具 | 行为 |
|---|---|
| `fishing_cast` | 抛竿（立刻咬钩），返回本竿生效概率（含天气）+ 预抽手感 `preRarity` |
| `fishing_reel` | 收杆（中鱼结算，行情鱼按倍率） |
| `fishing_status` | 状态 + 金币 + 增益 + 任务进度 + **签到 / 今日行情 / 天气鱼情** |
| `fishing_fishdex` | 图鉴进度（/100）+ 生涯统计 + **里程碑达成进度** |
| `fishing_giveup` | 收竿回家 |
| `fishing_shop_list` | 商店列表（价格/效果/竿数/叠加规则） |
| `fishing_shop_buy` | 购买道具（itemId），响应带购买后真实概率 |

> v0.5.1：工具声明改为宿主 Agent 适配层要求的 `{ description, parameters }` 形状。
> v0.5.0 的扁平写法会被适配层当作无参工具，LLM 传入的 `itemId` 在参数转换时被整体剥掉。

## 三类能力

| kind | 入口 | 做什么 |
|---|---|---|
| `tool` | `tool/index.js` | 常驻层：游戏主循环（5 秒巡检）、会话管理、结算、概率与增益、每日经营圈、徽标、7 个 Agent 工具；activate 时把 `catalog`（100 鱼花名册）与 `shop`（道具表）写入 storage |
| `panel` | `panel/panel.html` | 钓鱼面板：水面状态卡（空闲/等待/咬钩三态 + 增益徽章 + 行情/天气条）、渔获记录、图鉴页签、任务页签（签到行 + 任务）、商店页签 |
| `dashboard-card` | `card/card.html` | 看板卡片：统计 + 状态 + 行情/天气行 + 抛竿/收杆快捷按钮；图鉴分母从 `catalog` 动态读取 |

**单一数据源**：鱼种表和商店表只维护在 `tool/index.js`，通过 storage 的 `catalog` / `shop` 键下发给面板与卡片，改数值只改一处。

panel/card 不直接改游戏状态，统一通过 `events.emit('fishing:action', {action:'cast'|'reel'|'buy', itemId?})` 请求常驻层执行，避免三方写冲突。

## 联动事件（其它插件可监听）

- `fishing:bite`：抛竿咬钩发生 `{at, windowMs, preRarity}`
- `fishing:changed`：存档变更 `{scope:'fishing'}`
- `fishing:action`：panel/card → tool 的动作通道（内部）
- **监听** `todo-reminder:completed`：todo 插件的完成契约事件 `{id, text, doneAt}`（跨插件， todo-reminder v1.0.3+）

## 权限（9 项）

| 权限 | 用途 |
|---|---|
| `storage` | 金币、鱼图鉴、捕获记录、道具、任务与签到进度存于插件私有存储，卸载即随之删除 |
| `pet` | 咬钩时让桌宠冒泡、播放动作，设置宠物脚下的状态徽标 |
| `ui` | 打开与关闭插件面板 |
| `events` | 面板与卡片之间同步游戏状态变化；对外广播 `fishing:bite` / `fishing:changed` |
| `scheduler` | 驱动挂机等待、咬钩判定、每日任务重置与签到刷新 |
| `tools` | 向宿主 Agent 注册 7 个游戏操作工具 |
| `ai` | SR/SSR 上鱼的专属台词、里程碑祝贺、鱼市行情吆喝（见下方说明） |
| `dashboard` | 在看板挂载本插件的卡片区块 |
| `net:api.open-meteo.com` | 拉取北京现况天气，把天气映射成鱼情增益（见下方说明） |

**未申请、也不使用的**：`clipboard`、`appearance`、`files`、`secrets`、`character:read`、`errands`。
除 `api.open-meteo.com` 外**不访问任何其它域名**。

### `ai`（实验）的使用边界

走**宿主自带的大模型**（`pet.ai.chat`），**不读取也不需要任何 API Key**，不申请 `secrets` 权限。
全部是一次性游离任务（SR/SSR 台词、里程碑祝贺、行情吆喝），合计远低于宿主 10 次/分的限流。
宿主未配置大模型或调用被限流时，**静默降级为预写文案**，不影响结算与玩法。

### `net:api.open-meteo.com` 的使用边界

- **用途**：调用 open-meteo 免 key 的公开天气接口，取北京现况 `weather_code`，
  映射成鱼情增益（与道具增益同机制）。
- **范围**：只有一个域名，只发这一个 GET 请求；结果缓存 3 小时。
- **失败处理**：请求失败静默降级为「无天气影响」，30 分钟后重试，**不阻塞任何玩法**。
- **不发送任何用户数据**：请求只带经纬度与时区参数，**不上传钓鱼数据、存档或任何个人信息**。

### 其它说明

`ai` 用于 SR/SSR 台词、里程碑祝贺、行情吆喝（均为一次性游离任务，合计远低于宿主 10 次/分限流）；
无 key 或限流时静默降级预写文案，不影响结算。

## 开发与验证

```bash
# 校验 manifest、打包清单与政策红线（含联网域名核对），并产出 dist/plugin.zip
node scripts/build.js

# 只校验不产出（CI 的 PR 检查用）
node scripts/build.js --check-only

# 校验标签与 manifest.version 一致（CI 发布前用）
node scripts/build.js --check-only --check-tag v0.5.1

# 用宿主真实安装管线校验产出的包（解压 / manifest / 权限比对）
node scripts/verify-install.js
```

`scripts/build.js` 在打包前会强制检查：

- manifest 字段合法（ID 格式、`x.y.z` 版本号、description 单行且 ≤200 码点）
- manifest 声明的入口全部在打包清单里，且清单文件全部存在
- **政策红线扫描**：Node 内建模块 `require`、动态 `require`、`eval`/`new Function`
- **联网域名核对**：代码里出现的每个域名都必须已在 `manifest.permissions` 声明
  `net:<hostname>`，未声明即构建失败（变量形式的 URL 会回溯全包域名一起核对）

ZIP 顶层直接是 `manifest.json`（宿主安装管线的解析要求），文件顺序固定、时间戳归零，
保证同样的源码打出同样的包与摘要。

## 已知取舍（细节待改）

- **抛竿即咬钩**：v0.1.1 起点抛竿立刻进入咬钩态（应「点了就想钓上鱼」的需求）；
  等待/空军机制代码保留为兜底路径，可在 `castRod` 里改回随机 `biteAt` 恢复挂机玩法。
- **重启不追赶会话**：宿主重启后旧钓鱼会话直接视为跑鱼，不做离线结算；增益耐久不受重启影响（存在存档里）。
- **徽标只反映钓鱼状态**：不常驻显示金币/图鉴进度（与 todo 插件抢徽标名额时静默让位）。
- **AI 台词不回填历史**：台词只补写「最新一条」渔获记录（ts 对齐防竞态），快速连竿时旧台词会放弃入档，只冒泡。
- **天气默认北京**：坐标写死在 `WEATHER_URL`，想换城市改它即可；做城市设置面板属后续需求。
- **日报错过不补**：23:58 宿主不在线就没播报；今日数据在下次触达时惰性归零，不会串天。
- **老存档兼容**：v0.2.0 之前的进行中会话没有 `preRarity`，收杆时按当前概率兜底重抽一次；v0.4.0 之前的存档没有 sign/market/weather 字段，读档时自动补默认值。
- **todo 联动单向容错**：`todo-reminder:completed` 收不到（插件未装/旧版）只是没有佣金，不影响钓鱼本体；
  任务列表每天随机 3/7，想固定任务改 `QUEST_POOL` 抽取逻辑即可。
